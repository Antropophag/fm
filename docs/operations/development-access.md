# Dev FM — домашний сервер

По решению владельца от 18.11.2026 домашний сервер считается dev.
Корпоративный [production](production-access.md) находится на `fm.shlz.ru`.
Переименование касается назначения контура; DNS, пути, контейнеры и настройки
интеграций этим решением не менялись.

## Доступ

- Портал: https://fmonitor.antropophag.ru/.
- Внутренний SSH: `ssh antropophag@192.168.0.148`.
- Внешний SSH, предоставленный владельцем: `ssh -p 22222 antropophag@80.251.125.77`.
- После SSH на Windows-хост: `wsl -d Ubuntu-24.04`.
- Checkout в WSL: `/home/antropophag/code/fmonitor-2`.
- Compose project: `fm2-local-antropophag`.
- Контейнеры: `fm2-local-antropophag-{web,php,db,jobs-worker,jobs-scheduler}-1`.
- Приложение в контейнере: `/workspace/fmonitor-2`.

Адреса предоставлены Тимофеем Гришиным 21.09.2026 и сохранены по его поручению
13.11.2026. Тогда подтверждены внутренний SSH, Windows-хост `DESKTOP-7EHPNJR`
и запуск Ubuntu-24.04; внешний SSH отдельно не проверен.
Для автоматизации работает `ssh ... 'wsl -d Ubuntu-24.04 -- python3 -'`
с программой на stdin. Пароли, ключи и токены хранятся вне Git.

## Работа с dev

Перед изменением сверять checkout и файлы работающих контейнеров: там могут быть
ещё не перенесённые в Git правки. Сохранять их и резервные копии вне репозитория.
На домашнем сервере ранее работали реальные ERP, Битрикс и SMTP; название dev
не означает тестовые данные или отключённую отправку писем. Перед проверками
уточнять фактические подключения и выполнять действия в рамках поручения.

Исторические записи до 18.11.2026, называющие этот сервер production или
production-first, относятся к домашнему контуру. Они не дают разрешения на
изменение корпоративного production.
