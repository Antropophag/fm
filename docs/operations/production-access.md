С 18.11.2026 production означает корпоративный FM. Домашний сервер —
[dev](development-access.md). Исторические упоминания домашнего production
сохраняются как история и не задают адрес текущего production.

## Адреса и установка

- Портал: https://fm.shlz.ru/.
- Portainer: https://10.178.80.4:9443/; окружение `local` (ID 3 на 17.11.2026).
- Репозиторий для выкладки: http://10.178.69.56/ts.grishin/fm, ветка `main`.
- Каталог на сервере: `/opt/fm2`; Compose project: `fm2-prod-fm`.
- Контейнеры: `fm2-prod-fm-{web,php,db,jobs-worker,jobs-scheduler}-1`.
- Приложение в контейнере: `/workspace/fmonitor-2`.
- Веб-порт на сервере: `127.0.0.1:8093`, внешний адрес работает через HTTPS-прокси.

Перед работой проверить корпоративный VPN, доступность адреса и фактический
Compose project. Имена внутренних каталогов и контейнеров сохранены.

- Пароль и ссылки на первоначальные реквизиты портала хранятся вне Git:

  приватном manifest `~/.local/share/fmonitor-2/fm-admin-env-handoff/artifact-location.json`.

- Логи и выполнение команд внутри контейнеров через Portainer проверены.
  Диагностика БД выполнялась из `jobs-worker` с его runtime-переменными;
  пароли не выводить. Внешний SQL-доступ отдельно не подтверждён.
- 17.11.2026 SFTP на `fm.shlz.ru:22` с этой учёткой открывал только
  `/configurator` другого проекта; SSH-команды были запрещены. Доступ к каталогу

Секреты читать только из приватных файлов для нужного сервиса. Если файлов нет
на текущей машине, запросить реквизиты у владельца; домашний dev не является
заменой production.

## Обновления

Штатный маршрут на сервере: `cd /opt/fm2 && git pull --ff-only && make update`
под пользователем существующей установки, с её `.env` и каталогом состояния.
В GitLab переносится проверенный `main` из GitHub `Antropophag/fm`.

У выданной учётки не подтверждён способ запуска серверного обновления.
Консоль контейнера приложения не имеет доступа к серверному checkout и Docker.
Задача выкладки в GitLab или служебный контейнер обновления только предложены,
их настройка не подтверждена. SFTP сам по себе обновление не выполняет.
