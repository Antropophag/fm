## Purpose

Единый свободный поиск адресов и подъездов во всех существующих списках FMonitor без требования к формату ввода и без изменения фактов.

## ADDED Requirements

### Requirement: Shared address search
Система SHALL выполнять FLEXIBLE-ADDRESS-SEARCH-001 A1–A8 на всех перечисленных public seams, сохраняя права, историю и точные числовые ограничения.

#### Scenario: Natural address and entrance
- **WHEN** пользователь вводит неполный адрес, сокращения, переставленные явно помеченные компоненты или небольшую опечатку в названии
- **THEN** доступные объекты найдены по общей грамматике, а дом, корпус, строение и подъезд не подменяются похожими числами.

#### Scenario: Pagination and current data
- **WHEN** совпадающий объект находится за первой страницей или адрес исправлен
- **THEN** новый запрос учитывает его до подсчёта/пагинации без ручной переиндексации.

#### Scenario: Offline and preserved scope
- **WHEN** пользователь ищет среди сохранённых объектов без сети
- **THEN** применяются те же правила только к фактически сохранённым в его области объектам, без новых бизнес-фактов.
