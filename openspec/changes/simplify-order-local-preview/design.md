# Решение

Используем существующий регистр идентичности; сохраняем последний PDF как неизменяемый артефакт/факт формирования; внешний номер связан с принятой редакцией. Yii — адаптер, факты принадлежат application seam. Миграция additive; историческим документам номер не придумывается. Развёртывание только локально с копией данных. Recovery/frontier/full consumers и независимые reviews остаются частью последующей интеграции.
